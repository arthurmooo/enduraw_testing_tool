# Installer Enduraw Testing Tool sur le PC de Kylian

Kylian n'a besoin d'installer ni Python, ni Node.js, ni Git, ni MongoDB.

1. Recuperer le fichier `EndurawTestingTool-Setup.exe` transmis par Arthur.
2. Double-cliquer sur le fichier.
3. Si Windows affiche SmartScreen, verifier que le fichier vient bien d'Arthur, puis cliquer sur **Informations complementaires** et **Executer quand meme**.
4. Garder le dossier propose et cliquer sur **Installer**.
5. Laisser coche **Lancer Enduraw Testing Tool**, puis cliquer sur **Terminer**.

L'application est ensuite disponible sur le Bureau et dans le menu Demarrer.
La fenetre de graphiques MetaSoft s'ouvre dans le navigateur Windows, sans serveur externe.

## Mise a jour

Fermer Enduraw Testing Tool, puis lancer le nouveau `EndurawTestingTool-Setup.exe`.
Il remplace l'application sans supprimer les sessions, profils ou exports locaux.

## Desinstallation

Utiliser **Parametres > Applications > Applications installees > Enduraw Testing Tool > Desinstaller**.
La desinstallation retire l'application et ses raccourcis, mais conserve les donnees locales.

## En cas de blocage

- Faire une capture du message affiche.
- Ne pas supprimer manuellement les dossiers de donnees.
- Envoyer la capture a Arthur avec l'etape qui bloquait.

Le setup n'est pas encore signe avec un certificat Windows. SmartScreen peut donc afficher un avertissement meme si le fichier est intact.
